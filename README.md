# Data Engineer Technical Assessment

Prueba técnica de ingeniería de datos desarrollada en Google Colab utilizando Python, SQL y PySpark.

## Ejercicios realizados

**SQL**

- Procesamiento de resultados de partidos y cálculo de puntos.
- Clasificación de equipos por grupo.
- Identificación de equipos élite mediante quintiles.

**PySpark**

- Creación y transformación de DataFrames.
- Ranking de jugadores según goles por partido.
- Procesamiento de centros educativos mediante distancia euclidiana.
- Exportación de datos en formatos Parquet, JSON y CSV.

## Ajustes técnicos

- Actualización de PySpark a la versión 4.0.1.
- Configuración de Java 17.
- Adaptación de SQLite al entorno de Google Colab.

## Ejecución

El notebook contiene las soluciones de los ejercicios y las salidas de ejecución correspondientes.
